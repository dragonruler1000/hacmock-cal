# Hammock-calc
A simple python program that has calculators for varius calculations for making and using a hammock.
the advalible calculators are:
- catanary curve
- hammock placement height and tension
- tarp sizing and anchor placment
- unit converter
- total weight of hammock
  
## How to use
### Recomended
download and run the latest build from [releases](https://github.com/dragonruler1000/hacmock-cal/releases/latest)

### Build from source
Clone the repo and enter the folder
```bash
git clone https://github.com/dragonruler1000/hacmock-cal.git
cd hacmock-cal
```
make a venv
```bash
python -m venv .venv
```
install pip and matplotlib
```bash
python -m ensurepip --upgrade
pip install matplotlib
```
run main.py
```bash
python /src/hacmock_cal/main.py
```
